## 报告结构

### 一、项目概述
- 项目定位：方舟智库（Arkmind）— IT 售前项目管理桌面应用
- 技术栈：Tauri v2 + Rust + Vue 3 + Pinia + SQLite + LanceDB

### 三、代码审计（5 个维度）

#### 3.1 安全性（20 项发现）
| 级别 | 问题 | 位置 |
|------|------|------|
| CRITICAL | 前端直连原始 SQL 执行（SQL 注入） | `db_commands.rs:4-6`, `db-client.ts:345-347` |
| HIGH | 硬编码公钥（许可证破解风险） | `license.rs:13` |
| HIGH | 弱密钥派生（单次 SHA-256，无 KDF） | `crypto.rs:10-17` |
| HIGH | CORS 通配符（信息泄露） | `lib.rs:62` |
| HIGH | API 密钥明文返回前端 | `settings_commands.rs:60` |
| HIGH | v-html XSS（FilePreview 无消毒） | `FilePreview.vue:135` |
| MEDIUM | FTS5 搜索注入 | `agent_workflow.rs:772` |
| MEDIUM | DOMPurify 允许 `<input>` 标签 | `sanitize.ts:10-13` |
| MEDIUM | API 密钥存于 reactive 状态 | `Settings.vue` |

#### 3.2 错误处理（3 类模式问题）
- **Mutex 中毒级联**：多处 `.lock().unwrap()` — 一次 panic 导致全应用崩溃
- **静态初始化 panic**：`.expect()` 在 HTTP client/tokio runtime 创建时
- **静默错误吞没**：35+ 处 `.ok()` 和空 catch 块，关键路径（许可证激活）也受影响

#### 3.3 架构设计（5 项高风险）
- **God File**：`database.rs` (1782行) — DDL/FTS5/迁移/CRUD 混合
- **God File**：`agent_workflow.rs` (1400+行) — 会话/工具/搜索/元数据混合
- **God Component**：`ProjectDetail.vue` (2140行) — 项目元数据/渠道/供应商/笔记/待办/文件
- **God Component**：`Settings.vue` (1159行) — LLM/Vision/Vector 配置全部在一个组件
- **重复模块**：`license.rs` 完全重复两份

#### 3.4 性能问题（6 项发现）
- **数据库单 Mutex**：所有读写共享一个锁，并发阻塞
- **N+1 查询**：搜索循环中 60-360 次独立数据库查询
- **Tokio 阻塞**：LanceDB 操作通过 `block_in_place` 阻塞 worker 线程
- **无界 KeepAlive**：所有路由组件缓存无上限
- **Dashboard 重复加载**：每次 Tab 切换重新发起 6 个 API 调用
- **文件读取阻塞**：大文件在 async handler 中同步读取

#### 3.5 TypeScript/代码质量（10 项发现）
- **276 处 `any`**：API 层和视图层类型形同虚设
- **缺失导出**：`readFileBytes`、`fetchSolutionVersions` 运行时崩溃
- **状态管理反模式**：直接 mutation + store 更新双写
- **全局事件泄漏**：`document.addEventListener` 在模块作用域注册
- **空 catch 块**：35 处静默吞错
- **调试日志残留**：97 处 console.log

#### 3.6 可访问性（3 项 CRITICAL）
- **零 aria 属性**：整个前端无任何无障碍标签
- **无键盘导航**：下拉菜单、日历、聊天建议卡片无键盘支持
- **缺失表单标签**：textarea/input 无 label 关联

### 四、依赖安全
- `ed25519-dalek` 未锁定精确版本（加密库应固定）
- `once_cell` 可替换为 std（Rust 1.80+）

### 五、建议优先级矩阵
按 修复成本 × 影响范围 排序 Top 10 行动项

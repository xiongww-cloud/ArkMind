# LLM Policy 持久化方案

## 背景

用户希望为 LLM 设定规则（policy），使其在每次对话中都能遵守。当前系统没有持久化的全局策略机制。

## 方案设计

利用已有的 `system_settings` 表存储用户策略，每次 agent 对话时加载注入到 system prompt。

### 数据流

```
用户在设置页输入 policy
    ↓
调用 set_user_policies API → 写入 system_settings 表
    ↓
agent 每轮对话 → 加载 policy → 注入 system prompt
    ↓
LLM 始终遵守设定的规则
```

## 实施步骤

### Step 1：新增 API 接口

**文件：** `src-tauri/src/commands/settings_commands.rs`

```rust
#[tauri::command]
pub async fn get_user_policies() -> Result<Value, String> {
    let row = database::get(
        "SELECT value FROM system_settings WHERE key='user_policies'",
        &[],
    ).map_err(|e| e.to_string())?;
    Ok(json!({
        "success": true,
        "policies": row.and_then(|r| r["value"].as_str().map(String::from)).unwrap_or_default()
    }))
}

#[tauri::command]
pub async fn set_user_policies(policies: String) -> Result<Value, String> {
    database::run(
        "INSERT OR REPLACE INTO system_settings(key, value, updated_at) VALUES('user_policies', ?1, datetime('now','localtime'))",
        &[json!(policies)],
    ).map_err(|e| e.to_string())?;
    Ok(json!({"success": true}))
}
```

### Step 2：注册命令

**文件：** `src-tauri/src/lib.rs`

在 `generate_handler!` 中添加：`commands::get_user_policies, commands::set_user_policies,`

### Step 3：修改 System Prompt

**文件：** `src-tauri/src/services/agent_workflow.rs`

在 `AGENT_SYSTEM_PROMPT` 中添加占位符：
```rust
const AGENT_SYSTEM_PROMPT: &str = r#"你是企业级知识库智能助手。

## 当前日期
{{today}}

## 用户策略（必须遵守）
{{user_policies}}

## 当前会话工作记忆
{{session_scratchpad}}
...
```

### Step 4：加载 Policy 注入 Prompt

**文件：** `src-tauri/src/services/agent_workflow.rs`

在 `execute_agent_chat` 初始化时：
```rust
let user_policies = crate::database::get(
    "SELECT value FROM system_settings WHERE key='user_policies'", &[],
).ok().flatten().and_then(|r| r["value"].as_str().map(String::from))
    .unwrap_or_else(|| "无特殊策略要求。".to_string());

let empty_sys = AGENT_SYSTEM_PROMPT
    .replace("{{today}}", ...)
    .replace("{{user_policies}}", &user_policies)
    .replace("{{session_scratchpad}}", "");
```

同样在每轮循环中更新时也要注入。

### Step 5：前端设置页

**文件：** `src/renderer/src/views/Settings.vue`

添加"用户策略"多行文本框 + 保存按钮。

**文件：** `src/renderer/src/api/db-client.ts`

```typescript
export async function getUserPolicies(): Promise<{success:boolean;policies:string}> { 
  return invoke('get_user_policies') 
}
export async function setUserPolicies(policies: string): Promise<{success:boolean}> { 
  return invoke('set_user_policies', { policies }) 
}
```

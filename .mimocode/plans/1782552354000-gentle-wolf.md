# LLM 检索时添加拟人化进度文本

## 问题

AI 思考时圆点在跳动，但没有文字说明在做什么。用户看到的只是空的弹跳圆点。

## 根因

后端在工具执行期间不发出进度事件。`agent:thought` 只在 LLM 返回内容时触发，工具执行期间没有文本。

## 方案

后端在关键节点发出 `agent:progress` 事件，携带拟人化思考文本。

### 改动 1：后端 `agent_workflow.rs` — 在工具调度前后发送进度

```rust
// 工具开始执行前
if let Some(ref h) = app_handle {
    let _ = h.emit("agent:progress", json!({"msg": "正在检索相关知识..."}));
}

// 工具执行完成后
if let Some(ref h) = app_handle {
    let _ = h.emit("agent:progress", json!({"msg": "已找到信息，正在整理..."}));
}
```

具体位置：
- 工具调度前（line ~2619）：发送"正在检索..."
- 工具结果收集后：发送"已找到 N 条信息，正在分析..."
- LLM 调用前（line ~2224）：发送"让我想想..."

### 改动 2：前端 `KnowledgeBase.vue` — 监听 `agent:progress`

当前已有监听（line 209），无需改动。只需确保后端发出事件即可。

## 验证

- 发送搜索请求后，圆点旁边显示"正在检索相关知识..."
- 工具完成后显示"已找到信息，正在整理..."
- LLM 回答前显示"让我想想..."

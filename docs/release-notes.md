# Arkmind v14.4.7

小版本更新（v14.4.6 内容见对应 Release）。

## 本次变更
- **AI 确认卡片全面非阻断化**：提问默认改为"问完继续、任务跑完后随答复自动发卡"，不再打断执行——路线分叉、关键缺失等常规追问都走此路径；仅高危不可逆操作（删除、覆盖等）保留阻断确认（wait=true）
- **确认卡片新增「补充说明」输入框**：卡片底部固定一个多行输入，可与逐题答案一并提交，也可**不答题只填补充直接提交**——回答问题之外还能交代背景与额外信息
- **中断即忘**：中断（停止）后再提问，AI 不再续答或重提上一任务及其未答复的确认问题（同会话任务串行化 + 作废指令注入）；停止过程显示"正在停止…"直到真正结束，杜绝新旧任务并发串扰、事件串流
- **文档助手长文分批修复**：修复分批成文时第 4 章起追加被拒（"需要正文内容"）反复重试、预算耗尽中止的问题——历史压缩占位不再误导模型漏传正文，参数类错误增加针对性指引与日志
- 内部：新增 PDF 解析试验台 `tools/vlm-demo/`（浏览器端 VLM 提示词/模型对照实验，用于回移主程序 PDF 解析能力）；主程序内的临时 PDF demo 已全部剥离

# Arkmind v14.4.6

小版本更新（v14.4.5 内容见对应 Release）。

## 本次变更
- **Windows 大量解析闪退根治（OOM 定案）**：多份崩溃转储取证确认为内存耗尽直接杀进程（此类崩溃不写日志，正是"闪退无痕"的原因）。解析并发 5→2；txt/md/csv/json 超 30MB 不再整读入内存（标「不支持」）；内存不足（可用 <1.5GB）时解析队列自动暂停领取、逐步恢复（批次越大越稳）；每个解析任务记录内存水位到日志，后续排查直接有材料；Word/PPT 深解析改大栈线程（防病态嵌套文档撑爆栈）
- **数据目录可自定义**：设置 → 存储位置——数据库、上传文件、向量库、备份统一存放在一个目录下，可整体迁移到任意磁盘。迁移采用「拷贝-校验-切换」：完整拷贝 + 数据库完整性校验 + 文件对账全部通过才切换，**旧数据原样保留、任意时刻中断都不丢数据**；完成后重启生效。指针文件固定在默认根目录，自定义目录被外部删除时自动回退并警告
- **迁移后检查**：迁移完成后可一键**验证数据完整性**（数据库 + 新旧目录文件逐项对账）；**一键回切原路径**（零拷贝秒级切换）；**清理旧数据**（手动按钮 + 二次确认，校验未通过禁止清理）
- **设备清单版本可复制到其他清单**：版本概览「复制到…」——目标可选本项目内已有清单或就地新建设备清单；复制结果为目标清单的编辑中草稿，原版本不受影响
- **参数匹配：本清单历史版本优先**：新型号/空参数行自动回填时优先取本清单历史版本中调过的参数（删控标、改指标不再丢失），无历史才回产品库；单行「拉取」改为来源选择器——本清单各历史版本与产品库并列、点击哪项用哪项
- **行间「+」随处插入**：悬浮任意设备行/子网行，上下沿浮出「+」，缝隙即插入位置（添加设备/子网）；子网头部菜单扩为 4 项（含子网块外上下插入）；工具栏添加改顶部/底部二选；所有插入后自动滚动定位、设备行直接聚焦可输入
- **参数格显示修复**：字体加载后自动重算高度（根治"参数显示不全"）；收起态裁切处加渐隐提示；右下角操作按钮改底部独占操作条，**永不遮挡参数文字**
- **单行参数不再强制序号与标点**：检查/一键修复对单行参数不加「N、」序号、不补行尾句号（多行规范不变）
- **Excel 导入子网自动识别**：任意列纵向合并主格且无型号 → 默认子网；无型号单格文本行（子网标题行）→ 默认子网；无型号多格成行数据仍为设备。**子网行文本自动成为默认子网名**（向导预填可改），误判可一键切回
- **上传弹窗粘贴修复（macOS）**：弹窗内点击后粘贴失焦、截图粘贴静默失败、Finder 文件粘贴时好时坏三处根因修复——点击自动回收焦点、后端剪贴板增加截图数据回退、无条件走后端文件读取；三条通道均无结果时给出提示
- **AI 回答内链可点击并真正定位到对象**：回答中的软件内链接（`#/projects/…` 等）点击即跳转——项目直达详情，笔记/待办/产品/通讯录/邮件跳转后**自动选中并滚动到目标**（此前只跳页面要手动找）；浮窗聊天点击唤起主窗完成跳转；确认卡片内的链接同样可点击；顺带修复同链接重复点击无反应、跨目录/跨视图/跨 tab 定位失败等存量问题
- **AI 确认卡片增强**：发卡场景放宽到五类用户拍板决定（新增辅助动作取舍、AI 主动发起的修改确认）；支持非阻断询问（发卡后任务继续跑完，答案与卡片同帧呈现）；委托子 Agent 的提问**直达用户**（主 Agent 无法转述，用户看到的就是子 Agent 原文）
- **AI 笔记归属回显修正**：检索/详情不再把项目笔记与闪记误报为"未归类"——闪记显示「每日闪记」、项目笔记显示「项目：A、B」、笔记本笔记显示「笔记本：X」
- **招投标助手控标数量硬约束**：编制招标参数时 ★废标项整篇最多 1 条、▲加分项严格 2～3 条；证明材料只附 ▲ 项（防定向设标风险）
- **mac ⌘+点击多选修复**：项目文件列表多选在 mac 上 ⌘+点击无效的根因修复（选择被重复执行互相抵消）；使用指南与手册的快捷键提示按平台显示（mac ⌘ / Windows Ctrl）

# Arkmind v14.4.5

小版本更新（v14.4.4 内容见对应 Release）。

## 本次变更
- **设备清单表格化重构**：清单改类 Excel 表格（序号/名称/型号/参数多行格/数量/单位/单价/小计），参数默认收起两行可展开；子网升级为可折叠分组容器；行内一键拉取产品库参数、冲突可选覆盖或保留、立即回写产品库；Excel 跨行粘贴自动扩行；全局撤销/重做（Ctrl+Z / Ctrl+Shift+Z）；版本时间线改版（概览磁贴 + 设备型号折叠列表）
- **价格上浮（持久化）**：总价栏新增「价格上浮」——输入系数（如 1.2）并可切换乘法/除法（默认乘法），以原价为基线重算、改系数不复利；系数随版本保存，重开可见「已上浮 ×1.5」徽标，支持修改系数与一键还原原价
- **向上取整**：总价栏一键把所有设备单价向上取整（可撤销）
- **删除控标**：一键剥除 ★/▲ 符号与含「截图/证明/报告/盖章」的证明材料段（按标点切段，只删小段、不删整行），删后自动修复标点与序号
- **免激活发布**：移除许可证与试用机制，安装即用全部功能（存量本机加密配置无缝兼容）
- **macOS 设置页修复**：知识管线卡片内容空白（WebKit 渲染问题）根治，卡片保持双列布局
- **设备清单交互优化**：点击任意文本框自动选中该设备；修复 Shift 多选（含选中时误选中文本）；表头「展开/收起」改文本按钮；删除子网可选「仅删除子网（保留设备）/连同设备删除」；删除撤销条统一至右下角通知区；子网头加/删按钮改纯图标（无边框无底色）
- **设置页官网入口**：版本号旁新增「软件官网」直达 GitHub 项目主页（与网盘下载入口并列）
- **清理**：旧版遗留的「拓扑助手」空 Agent 条目启动时自动清除；README 商业声明更正为保留所有权利

## v14.4.4 · 官方下载渠道上线
- **官方下载渠道上线**：设置页版本号旁新增「百度网盘 / 夸克网盘」下载入口，点击直达最新安装包（提取码自动填充，悬停可见备用码）；网盘为永久文件夹分享，此后每次发版只需向网盘追加新包，应用内链接无需变动

## v14.4.3 · Windows 与 OCR 稳定性根治
- **Windows 闪退/整机假死根治（解析内存治理）**：文件解析全部改有界读取，大文件不再整读进内存；新增 200MB 解析尺寸闸（超限文件直接标「不支持」，不再进解析队列）；PDF/图片等重型解析改串行执行——大 PDF/批量 PDF 并发曾叠加出内存尖峰，是整机换页假死与 OOM 闪退的主因
- **panic 尸检日志**：Rust 异常现在写入数据目录 panic.log（含时间与代码位置），Windows 闪退不再无痕、可直接取证定位
- **长任务心跳续租**：文件解析等后台任务全程自动「报到」，慢而有进展的任务不再被 5 分钟卡死自愈误判重跑——大 PDF 渲染/重试阶段被反复重领重复做功（CPU/网络空转）的路径已根治；进程崩溃时心跳消失，5 分钟自愈照旧生效
- **OCR 页数上限 300 页**：超长 PDF（手册/标书合集）仅识别前 300 页并在文末注明截断，渲染内存与视觉模型调用数双重封顶（知识摄入口径 ~90MB/任务封顶）；未配置视觉模型的纯文本提取不受影响、仍全量

## v14.4.2 · 上传判重与收信可靠性
- **目录上传去重前置**：加入清单时即按「文件名+大小」过滤已存在文件（跳过项计数展示），500 上限只数新文件——超 500 个文件的目录反复选择同一目录即可分批传完
- **资料库空目录可删**：目录镜像留下的空目录链从父目录一键级联删除；删除文件残留的悬挂占位自动清理（"看着空却提示不为空、删不掉"根治）
- **邮箱收信须知 + 测试连接**：邮箱设置弹窗新增第三方客户端取信前提说明（后台开启 POP3/IMAP 服务、填授权码而非登录密码、文件夹权限勾选「已发送」）；新增「测试连接」按钮，网络/登录/文件夹可达性分级反馈
- **邮箱同步登录限频根治**：每轮每账户单次登录复用会话（登录频率 2-3 次/分钟→1 次），登录失败指数退避（1→2→4→8→16 分钟，30 分封顶）——「Login fail … login frequency limited」间歇报错不再出现
- **设备型号输入改幽灵预览**：敲键只保留自己的输入，产品库命中名以灰色尾缀悬示、Tab 或行尾 → 采纳；不再"抢字上屏"，中文输入法拼音不再被强制上屏

## 首次安装说明（重要）

- **macOS**：不会再出现「应用已损坏」。首次打开会提示「无法验证开发者」——

- **Windows**：SmartScreen 蓝窗 →「更多信息」→「仍要运行」。

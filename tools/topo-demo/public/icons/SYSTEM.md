# 拓扑图标设计系统（双色调扁平 · v1）

> 本文件是自绘图标 `src/graph/iconArt*.ts` 的唯一设计依据，新增图标必须走这里的令牌与几何助手。

## 画布与安全区

- `viewBox = 0 0 32 32`，四周 2px 安全边距
- 图标以「设备形象」为目标：一眼可辨认器件种类，而非抽象概念符号

## 颜色令牌（固定值，不随主题切换——深浅画布均可读）

| 令牌 | 值 | 用途 |
|---|---|---|
| 描边 S | `#3F4C63` | 所有轮廓线，strokeWidth 2，round cap/join |
| 主填充 F | `#DCE7F5` | 设备机身浅底（深画布上高对比可见） |
| 次填充 F2 | `#F1F5FB` | 面板/纸张/屏幕等第二层次 |
| 强调 A | `#3B82F6` | 流量箭头/端口/指示灯等功能语义 |
| 深强调 AD | `#2563EB` | 实心小元素（灯点/色块） |
| 反白 W | `#FFFFFF` | 强调色上的勾/孔 |

## 几何规范

- 机身圆角 `rx=3`（小型部件 rx=1~2）
- 线宽层级：轮廓 2 / 内部结构 1.5 / 强调细节 1.5~2
- 语义母题（跨图标复用，保持一致性）：
  - **机箱** = `chassis(w,h)` 圆角矩形
  - **转发箭头** = 水平/垂直双向箭头（路由/交换语义）
  - **端口排** = 底部一排小方块（交换/接入语义）
  - **无线弧** = 同心双弧 + 端点圆点（AP/无线语义）
  - **指示灯** = r1.6 强调色圆点
- 禁止：渐变、阴影、文字、位图、多色堆砌（除令牌外不引入第 6 色）

## 维护流程

1. 在 `iconArtA/B.ts` 用助手组合新图标
2. `npm run dev` 后访问 `http://localhost:5274/contact.html` 检查 contact sheet（白/深双底 + 40/88px 两档）
3. headless 截图审阅 → 修正 → 通过后登记进 `icons.ts`

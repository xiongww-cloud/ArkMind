ArkMind 安装说明（macOS）
========================

【安装步骤】
1. 将左侧的 Arkmind 图标拖入 Applications 文件夹
2. 从「应用程序」或启动台打开 Arkmind

【首次打开如提示「无法验证开发者」】
本安装包为本地签名、未使用 Apple 开发者证书，仅首次需要放行：
· macOS 14 及以下：在「应用程序」中右键点击 Arkmind → 选择「打开」→ 再次确认「打开」
· macOS 15 (Sequoia) 及以上：打开 系统设置 → 隐私与安全性 → 「安全性」区块底部 → 点击「仍要打开」

如提示「应用已损坏，无法打开」：按上述放行操作即可，文件本身完好。

【获取最新版本】
· 应用内：设置页 → 版本号旁「百度网盘 / 夸克网盘」链接
· 当前版本号可在设置页版本号处查看
